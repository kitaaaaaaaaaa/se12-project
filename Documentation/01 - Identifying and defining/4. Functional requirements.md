# Functional requirements
This lists the requirements that the software must fulfill in order to address the problem.

## Essential features
These features must be implemented in order to address the problem and achieve the desired outcomes.
- A homepage to view all events
- Ability to edit event run sheets before and during the event
- Function to 'play' the run sheet during the event and for admins progress it forward
- Function for members to view the digital run sheet filtered according to their specific role such that it is synchronised with the admin's progression through the run sheet
    - Their interface must be uncluttered and clean
- Authentication system to distinguish an administrator and a crew member

## Optional features
These features are beneficial, but not required to address the core problem. They are ranked based on how beneficial they are to the scenario.
1. Ability for admin to jump to a specific step for rehearsals
2. Toggle between light and dark mode interface
3. Function to print a paper copy of a run sheet
4. Support for mobile devices
