# Problem Definition
This page defines the problem in full, justifies the need for the software, outlines its benefits and how it solves the current problem.

## Problem
Crew members currently follow along using paper run sheets, which are hard to read in the dark and become quickly outdated. Some members view an up-to-date version of the run sheet using their laptop and Google Sheets. The disconnect between paper and online run sheets creates conflicts in the tasks that need to be carried out, creating confusion.

The run sheets also have an overwhelming amount of information, wasting time taken to interpret the run sheet and making it harder to juggle multiple responsibilities in a time sensitive environment. This leads to some tasks being missed or performed incorrectly, which disrupts the flow of the concert.

The sheer volume of tasks are exacerbated by the fact that crew members have to accomodate for students who do not know stage ettique, correct microphone handling and effective on-stage positioning. Crew members must take time to solve these problems rather than waste time interpreting the run sheet, which creates confusion and clouds their judgement.

## Target Audience
The software is built for teachers and event administrators to create, edit and delete run sheets before the event. The interface must be intuitive and easier, if not, as easy to use when compared to Google Sheets (the current solution). It is also built for crew members to use and view their instructions during the event.

## Benefits of the solution
The software, being a digital product, will be used on desktops/laptops, which are easier to read in the dark. It will also serve an up-to-date version of the run sheet, which can be changed during the event if neccessary. During the event, the software will only display instructions that are relevant to the crew member's role, making it less overwhelming, reducing decision fatigue and saving time. The software solution will improve clarity and thus, reduce the amount of technical errors during the event.

## Justification
The software is essential because:
- It promotes clarity in a team environment
- It reduces stress by making run sheets less overwhelming
- It lessens the amount of technical mistakes that happen
- More time can be allocated to troubleshooting more pertinent issues
