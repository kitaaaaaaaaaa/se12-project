# Functionality – Does it work as expected?
## The software meets the initial requirements and objectives

**What does this mean for my project? (If not relevant, say why.)** <br>
The software must have a home page to view different events and their run sheets. Users must be able to create, edit and delete run sheets, before and during the event. Admins should be able to progress the run sheet forward during the event, and crew members should be able to view this progression live. The software must also have an authentication system.

**How and when will I check this?** <br>
The Producing and Implementing stage is centred around sprints. Each sprint will culminate in one functional requirement being built, so the criteria will be fulfilled. If any problems arise after a sprint (e.g. time limitations), the requirements will be checked and revised.
