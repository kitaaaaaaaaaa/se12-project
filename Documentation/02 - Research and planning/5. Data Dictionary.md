# Data Dictionary
This page has multiple data dictionaries. A dictionary has been created for tables in the database that are used to store events, run sheets and the instructions associated with them. The [database schema](#database-schema) may also provide further context.

## Events Table
| Variable | Data Type | Format for display | Size in bytes | Size for display | Description | Example | Validation |
| --- | --- | --- | --- | --- | --- | --- | --- |
| event\_id | Integer | NNN | 3 | 3 | Auto-generated unique identifier for each event | 4 |   
| event\_name | String | XXX...XXX | 128 | 128 | Name of the event | School Concert |   
| event\_date | Date | DD/MM/YYYY | 4 | 10 | The date that the event occurs on | 31/04/2026 | Date > Today |
| event\_location | String | XXX...XXX | 128 | 128 | Where the event is held | School Hall |   

## Steps Table
| Variable | Data Type | Format for display | Size in bytes | Size for display | Description | Example | Validation |
| --- | --- | --- | --- | --- | --- | --- | --- |
| step\_id | Integer | NNN | 3 | 3 | Auto-generated unique identifier for each step | 24 |   
| event\_id <br> (from events table) | Integer | NNN | 3 | 3 | Auto-generated unique identifier for each event | 4 |   
| step\_num | Integer | NNN | 3 | 3 | The nth step to determine the order of the steps | 3 | Step number does not already exist for the same event |
| step\_title | String | XXX...XXX | 128 | 128 | The title of the step | Erase me by Lizzy Mcalpine |   
| step\_performer | String | XXX...XXX | 64 | 64 | The person or group that is on stage | Year 12 Band |   

## Instructions Table
| Variable | Data Type | Format for display | Size in bytes | Size for display | Description | Example | Validation |

| instruction\_detail | String | XXX...XXX | 128 | 128 | The instruction given to crew members | PLACE stool front stage |
