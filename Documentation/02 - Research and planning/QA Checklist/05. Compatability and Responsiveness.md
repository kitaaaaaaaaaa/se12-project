# Compatability and Responsiveness – Does it work everywhere?
## Cross-browser compatibility (tested in Chrome, Firefox, Safari, Edge).
**What does this mean for my project? (If not relevant, say why.)** <br>
The web application must function as intended across various browsers. It should work across major browsers such as Chrome, Firefox, Safari, Edge and Opera. It will not support older browsers such as Internet Explorer.

**How and when will I check this?** <br>
This will be checked when obtaining user feedback during the Testing and Evaluating phase. Feedback will be obtained from users with varying browsers. This will also be tested manually, checking that the 5 main essential features work as intended.

## The design is fully responsive on mobile, tablet, and desktop.
**What does this mean for my project? (If not relevant, say why.)** <br>
This is an optional feature and is not required for my project, since run sheets are often viewed and edited on desktops/laptops. Responsiveness will be built into the HTML/CSS using media queries, clamp functions and relative units, but will not be prioritised.

**How and when will I check this?** <br>
This will be checked during the creation of UI components in the Producing and Implementing stage using browser developer tools that can emulate smaller screen sizes.

## The application runs properly on different operating systems (Windows, macOS, Linux).
**What does this mean for my project? (If not relevant, say why.)** <br>
All the 5 essential features must work and function as expected on Windows and macOS, as a bare minimum. Support for Linux is not relevant in the context of the scenario because there are no users that use Linux.

**How and when will I check this?** <br>
This will be checked in the Testing and Evaluating phase by obtaining users who own devices that use macOS. Since the application will be developed on Windows, it will be compatible with Windows.

## If a PWA, it works offline and installs correctly.**
**What does this mean for my project? (If not relevant, say why.)** <br>
The web application must have a service worker and manifest file in order to be eligible as a PWA. Relevant code should be included to register the service worker. The service worker must cache all the necessary files needed for the application to work offline.

**How and when will I check this?** <br>
This will be checked throughout the Producing and Implementing stage using the browser developer tools.
