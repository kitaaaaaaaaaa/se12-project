# Testing

**Unit tests check individual functions/components.**

Has this criteria been met? *Yes*

Analysis: Upon manual review, every unit test only calls one function. Therefore, the criteria has been met.

<br>

**Integration tests ensure different parts of the system work together.**

Has this criteria been met? *Partially*

Analysis: Integration tests have been written and they do indeed simulate requests to the backend. Some tests have not been written due to their complexity, for example, if the server returns the correct set of events for the home page.

<br>

**User testing was conducted for feedback.**

Has this criteria been met? *Yes*

Analysis: Thee client was consulted after some key phases of the project and feedback was gathered. Two major feedback points were: after UI designs were finished, and after the entire system was finished.

**Bugs and issues were documented and resolved.**

Has this criteria been met? *Yes*

Analysis: Any issues were placed into the journal and solved if possible. Bugs were also tracked and resolved on Todoist. During the testing and evaluating phase, any new bugs that occurred were documentented accordingly.
