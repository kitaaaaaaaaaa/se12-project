# Usability

**The UI/UX (user interface/user experience) is clear, intuitive and easy to navigate**

Has this criteria been met? *Yes*

Analysis: During the research and planning phase, the UI/UX was finalised after some deliberation with clients and after testing the UI in real world conditions. Furthermore, when the software was given to the client, they manual observations suggested that they could navigate the interface with ease.


<br>

**Forms provide useful validation messages (e.g., "Password too short").**

Has this criteria been met? *Yes*

Analysis: Validation messages have been embedded into the website code, alerting the user what format the input must adhere to. The code has also been ordered in a way such that the most pertinent validation message overrides other errors. Additionally, after manual inspection while obtaining feedback from the younger client, it can be confirmed that all forms provide validation messages.


<br>

**Accessibility considerations (e.g., readable fonts, color contrast).**

Has this criteria been met? *Yes*

Analysis: After testing the colour contrast using the Web Accessibility Insights extension, it the offending UI elements were fixed. Logical font sizes were also considered throughout development, ensuring accessibility. The intial criteria lists a toggle between light and dark mode. This was not met, but it is not necessary for the site.

<br>

**Buttons, menus, and inputs are clearly labeled and responsive.**

Has this criteria been met? *Yes*

Analysis: After looking at every page, I can discern that all buttons, menus, inputs and methods of interaction have a visible label, or have a label when you hover over the element.
